# Atelier 09 — Architecture Demo

A motion-led, responsive architecture studio concept built with Next.js, React and Framer Motion. Includes a CSS 3D pavilion study, editorial project layouts, responsive navigation and a demo inquiry form.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Before using with prospects
- Replace the fictional studio identity, project details and placeholder images with approved client-specific content.
- Replace the example email address and connect the inquiry form to an email service or CRM.
- Add real social profile links.
- Verify image licensing and optimize images for production.

This is a concept/demo website. Studio details, project names and metrics are illustrative.
